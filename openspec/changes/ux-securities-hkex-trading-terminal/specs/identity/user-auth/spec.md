## Purpose

为个人用户提供安全、可隔离的登录入口，使收藏、模拟订单、持仓和订单历史始终绑定到当前账号。

## ADDED Requirements

### Requirement: 用户可以注册并登录

系统 MUST 支持用户使用用户名或邮箱和密码注册、登录及退出；密码 MUST 以强哈希保存，客户端不得收到密码或密码哈希。

#### Scenario: 注册成功

- **WHEN** 用户提交未被占用的身份信息和符合策略的密码
- **THEN** 系统创建账号并返回受保护会话
- **AND** 系统为账号创建默认模拟账户

#### Scenario: 重复身份注册

- **WHEN** 用户提交已存在的用户名或邮箱
- **THEN** 系统拒绝注册
- **AND** 返回稳定错误码而不泄露其他账号的敏感信息

### Requirement: 会话必须保护用户数据

系统 MUST 对需要登录的行情收藏、订单、持仓和账户接口执行会话认证，并在服务端按会话用户过滤数据。

#### Scenario: 未登录访问受保护接口

- **WHEN** 请求未携带有效会话
- **THEN** 系统返回未认证错误
- **AND** 前端引导用户进入登录页面

#### Scenario: 用户读取他人数据

- **WHEN** 用户尝试通过修改路径参数读取另一个用户的收藏、订单或持仓
- **THEN** 系统返回资源不存在或无权访问
- **AND** 不返回另一用户的数据

### Requirement: 退出和过期会话必须失效

系统 MUST 支持退出、会话过期和服务端撤销；被撤销或过期的会话 MUST 不能继续调用受保护接口。

#### Scenario: 用户退出后访问接口

- **WHEN** 用户退出后再次请求账户接口
- **THEN** 系统返回未认证错误
