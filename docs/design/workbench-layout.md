# 品牌工作台追加合同（2026-10-24）

本合同记录用户追加的默认市场列表、收藏/持仓标记、三栏与协调背景要求，沿用已有认证、数据来源和模拟交易边界。

## 业务与可见性

- 登录后默认 Market，空查询直接列出已导入的港股股票目录；搜索只筛选，清空后恢复全部。不得以三个演示标的冒充全市场。
- My favorites 只展示当前用户收藏，可排序；市场列表内使用金色星标及 Favorite 文字。当前用户持仓使用青色菱形及 Position 文字；可同时显示，两者均非涨跌颜色。
- 桌面左侧证券列表，中间报价与九周期 K 线，右侧模拟限价单和紧凑可用资金。完整账户、持仓及订单历史只在 My positions 显示。成交后重新读取当前用户持仓及资金。
- 默认过去半年 K 线、分钟数据可用窗口、60 秒刷新、错误/空态、真实来源与 stale 提示继续有效。目录没有报价时不得编造价格或 mock 历史。
- UX 原始 Logo 保持比例，以小块浅色底座保证黑色字可读。整个页面背景、页头、列表、图表与表单使用一致深蓝灰表面；Logo 蓝强调交互，绿涨红跌且带百分比符号。移动端按列表、图表、下单顺序堆叠。

## API 与数据合同

- `GET /api/v1/markets/symbols?query=`：query 改为可选，空值返回目录；按代码排序，不再固定截断 50 条。保留 80 字符限制与登录保护。
- `MarketSymbol.quote` 可选，字段沿用 Quote；仅实际缓存存在报价时附带。缺失、过期数据分别显示 unavailable、stale，不把静态目录当实时行情。
- 官方 ListOfSecurities.xlsx 仅导入 Equity 且币种 HKD 的代码/名称/手数，不导入窝轮、牛熊、债券，不请求官方网页报价。
- 导入脚本使用事务、按唯一 symbol 新增/更新元数据；不得覆盖报价、历史、用户、账户或订单。目录来源与文件声明日期必须记录，若来源日期在本地日期之后必须明确披露，不能称作当日快照。
- 新目录记录 quote 字段为 NULL、data_status=unavailable。已有数据保留。无需业务表结构迁移；回退目录只能针对本次新增且无业务关系的记录，经核实后另行执行，不通过删除重建 stocks 回退。

## 文件与验证

- `pages/WorkbenchPage.tsx` 管理导航、活动证券和列表；`features/market/MarketSidebar.tsx` 展示/筛选/标记。
- `pages/TradingPanel.tsx` 下单及紧凑资金，`features/trading/PortfolioPanel.tsx` 独立账户、持仓、历史；共享数据 hook 避免重复持仓来源。
- `styles.css` 作用于工作台的深色终端主题，认证页沿用原品牌壳。
- 行为测试覆盖无需搜索、空态/失败重试、收藏及持仓标记、专页隔离、下单区域及订单后刷新；API 测试覆盖空查询及超长输入。隔离 MySQL 验证完整目录与 NULL 报价。
- 测试命令：`npm run test:frontend`、`npm run build`、`go test ./... -count=1`、`go vet ./...`。证据落在 change `results/workbench-layout/`；浏览器截图只声明实际视口，原三视口/上游整体门禁不能据此自动勾选。
